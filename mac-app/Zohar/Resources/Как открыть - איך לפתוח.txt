Zohar — пульт света для Mac

1. Перетащите Zohar в папку «Программы» (Applications).
2. Первый запуск: правый клик по Zohar → «Открыть» → «Открыть».
   Если macOS не даёт: Системные настройки → Конфиденциальность и безопасность →
   внизу «Zohar» → «Всё равно открыть».
3. Подключите Enttec / USB DMX → в Zohar шестерёнка (Настройки) → выберите порт usbserial.

---

Zohar — קונסולת תאורה למק

1. גררו את Zohar לתיקיית Applications.
2. פתיחה ראשונה: קליק ימני ← ״פתח״ ← ״פתח״.
   אם חסום: הגדרות מערכת ← פרטיות ואבטחה ← ״Zohar״ ← ״פתח בכל זאת״.
3. חברו Enttec / USB DMX ← גלגל שיניים (הגדרות) ← בחרו פורט usbserial.
