# Заметки для Claude

## Полезные ресурсы (сохранено по просьбе пользователя)

Использовать, когда задача подходит. Сторонний код и архивы сначала проверять, потом ставить.

### Minicharts: графики-рисунки из цифр
- https://april-zhu.com/minicharts
- Бесплатный скилл для Claude (MIT). Рисует графики по цифрам в виде предметов из темы (расходы — пирог из монет и т. п.), с точным масштабом.
- Принимает CSV/Excel, вставленные ячейки или просто цифры.
- Установка: Claude.ai — файл https://april-zhu.com/minicharts/minicharts.skill (Settings → Capabilities → Skills); Claude Code — архив https://april-zhu.com/minicharts/minicharts.tar.gz в `~/.claude/skills`.
- Родственный скилл для схем и процессов: https://april-zhu.com/tinycharts
- Когда пригодится: инфографика для постов, отчёты по YouTube-каналу, графики на страницах клиентов.

### Моды Claude Code: свои панели, команды, темы
- https://code.claude.com/docs/en/plugins/mods/interface
- Справочник: https://code.claude.com/docs/en/plugins/mods/reference
- Примеры: https://code.claude.com/docs/en/plugins/mods/gallery
- Мод — плагин на JS/TS: боковая панель, строка над полем ввода, всплывающие уведомления, команды `/...`, цвета вкладки Code в приложении.
- Рисует только в терминале, приложении для компьютера и VS Code; в облачной сессии не рисует. Нужен Claude Code 2.1.287 или новее.
- Для создания использовать скилл `plugin-authoring`.
- Идеи: панель «Мои события» из Google Calendar, команда `/рав` со статусом уроков, тема в цветах студии.

### DesignBookmark Motion: анимации для сайтов
- https://designbookmark.com/motion
- Около 80 живых анимированных элементов для сайтов (кнопки, меню, карточки, текст). У каждого есть кнопка «Copy for Claude».
- Только веб; для видео и титров не подходит. Лицензию сначала проверить: https://designbookmark.com/terms
- Подходит для сайта `films`: переворот страницы (превью альбома), колода карточек со свайпом (фото), переключатель тарифов (`mechir`), печатающийся заголовок на страницах клиентов.
