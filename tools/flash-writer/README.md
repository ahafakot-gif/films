# Запись флешек — אליעזר הפקות

Программа сама: форматирует флешки в **NTFS**, даёт им **название папки работы**, записывает выбранные файлы, проверяет и **закрывает флешки от записи и удаления**.

## Установка (один раз)
1. Скачать `flash-writer.zip`, распаковать.
2. Двойной клик на **`Установить.cmd`**.

## Как пользоваться
Правая кнопка → **«Записать на флешки (работа)»** (в Windows 11 сначала «Показать дополнительные параметры»):
- на **флешку** (можно выделить сразу 2–3 флешки) — программа сама спросит папку работы;
- на **папку работы** — флешки выберете в окне;
- на **файлы** в папке — они уже будут отмечены.

Или ярлык **«Запись флешек»** на рабочем столе.

В окне: отметить флешки → папка → отметить файлы → **СТАРТ** → подтвердить. Флешки пишутся одновременно.

## Важно
- Показываются только USB-флешки и SD-карты. Жёсткие диски компьютера не показываются и не трогаются.
- Защита: на флешке у всех только право чтения — нельзя удалить, изменить, добавить файлы. Администратор другого компьютера в принципе может снять защиту через свойства безопасности, обычный человек — нет.
- Перезаписать такую флешку потом можно этой же программой (форматирование снимает защиту).
- Журнал работы: `%LOCALAPPDATA%\FlashWriter\log.txt`.
- Удалить программу: `Удалить.cmd`.
